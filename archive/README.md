# University IT Material Management System

A clean, offline-first inventory application for a university IT department.

## Features
- Dashboard
- Material CRUD: name, category, quantity, reorder level, location, condition, serial number, responsible person, supplier, unit price, purchase date, description
- Search and filters
- Categories and suppliers CRUD
- Stock status: in stock, low stock, out of stock
- Reports and print report
- JSON backup and restore
- LocalStorage persistence
- English / Pashto toggle
- Dark mode
- No login and no server required

## Run
Open `index.html` directly in Chrome/Firefox/Edge. The application works offline and stores data in browser localStorage.
